# 🧟 ゾンビ タイムアタック FPS (Zombie Time Attack FPS)

**Unreal Engine 5.4.4** を使用して開発されたファーストパーソン・シューティング（FPS）ゲームです。プレイヤーは無情なカウントダウンがゼロになる前に、武器を駆使してゾンビの攻撃を防ぎ、制限時間内にできるだけ多くの敵を倒す必要があります。

このプロジェクトはC++コードを一切使用せず、**完全なブループリント（100% Blueprints）** で構築されています。UE5のブループリントロジックの学習や、ラピッドプロトタイピングのテンプレートとして非常に適しています。

---

## ✨ 主な機能 (Core Features)

*   **完全なブループリント設計:** コーディングのハードルはゼロ。キャラクター制御、ゲームモード、UIロジック、AIの挙動など、すべてがUE5のブループリントで駆動しています。
*   **タイムアタックモード:** 緊張感のある制限時間付きのゲームプレイ。画面にリアルタイムでカウントダウンが表示され、時間がゼロになるとゲーム終了となります。
*   **本格的なFPSメカニクス:**
    *   🎯 **エイム (ADS):** 右クリックでスムーズにアイアンサイトを覗き込む視点切り替え。
    *   🔄 **弾薬管理 (Reloading):** 射撃時の弾薬消費と、Rキーによるタクティカルリロード機能。
    *   🏃 **タクティカルムーブメント (Sprinting):** Shiftキー長押しでダッシュ。走行時のシームレスなステート移行を含みます。
*   **爽快な戦闘フィードバック:**
    *   💥 **ヒットバック (Knockback):** 弾がゾンビに命中すると、物理演算またはアニメーションによるリアルなノックバック効果が発生し、射撃感が大幅に向上しています。

## 🎮 操作方法 (Controls)

| キー | アクション |
| :--- | :--- |
| **W, A, S, D** | 移動 |
| **マウス** | 視点移動 / エイム |
| **左クリック (LMB)** | 射撃 |
| **右クリック (RMB)** | エイム (ADS) |
| **R** | リロード |
| **左Shift** | ダッシュ |
| **Esc** | ポーズ / ゲーム終了 |

---

## 🛠️ 実行方法 (How to Run)

1. ご使用のPCに **Unreal Engine 5.4.4** がインストールされていることを確認してください。
2. このリポジトリをクローンまたはダウンロードし、ローカルに展開します。
3. ルートディレクトリにある `.uproject` ファイルをダブルクリックして、UE5エディタでプロジェクトを開きます。
4. コンテンツブラウザからメインレベルを開き、上部ツールバーの **プレイ (Play)** ボタンをクリックしてゲームを開始します。

## 📁 ディレクトリ構成 (Project Structure)

*(注: 実際のフォルダ構成に合わせて調整してください)*
*   `Content/Blueprints/` - プレイヤーキャラクター、ゾンビAI、武器、ゲームモードコントローラーなどのコアブループリントを格納しています。
*   `Content/Animations/` - キャラクターやゾンビのモンタージュ、アニメーションブループリント (AnimBP) などのアセットを含みます。
*   `Content/UI/` - クロスヘア、残弾数、カウントダウン表示などのユーザーインターフェースウィジェット (UMG) を含みます。
*   `Content/Maps/` - ゲームのレベル（マップ）データです。
