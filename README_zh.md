# 🧟 限时丧尸生存 (Zombie Time Attack FPS)

基于 **Unreal Engine 5.4.4** 开发的一款第一人称射击（FPS）游戏。玩家需要在无情的倒计时结束前，利用手中的武器抵御丧尸的进攻，并在限时内尽可能多地消灭敌人。

本项目完全采用 **纯蓝图 (100% Blueprints)** 节点开发，没有包含任何 C++ 代码，非常适合作为 UE5 蓝图逻辑的学习参考或二次开发的模板。

---

## ✨ 核心特性 (Features)

*   **纯蓝图架构:** 零代码门槛，所有角色控制、游戏模式、UI 逻辑与 AI 行为均由 UE5 蓝图驱动。
*   **倒计时挑战 (Time Attack):** 紧张刺激的限时机制，屏幕实时显示倒计时，时间归零即结算。
*   **完整的 FPS 基础机制:**
        *   🎯 **瞄准系统 (ADS):** 丝滑的右键机瞄视角切换。
        *   🔄 **弹药管理 (Reloading):** 包含开火消耗与 R 键战术换弹逻辑。
        *   🏃 **战术移动 (Sprinting):** 支持按住 Shift 键进行冲刺奔跑，包含跑动时的状态切换。
*   **扎实的战斗反馈:**
        *   💥 **受击击退 (Knockback):** 子弹命中丧尸时会触发真实的物理或动画击退效果，大幅提升射击手感。

## 🎮 按键说明 (Controls)

| 按键 (Key) | 功能 (Action) |
| :--- | :--- |
| **W, A, S, D** | 前后左右移动 |
| **鼠标移动 (Mouse)** | 视角控制 |
| **鼠标左键 (LMB)** | 开火射击 |
| **鼠标右键 (RMB)** | 瞄准 (机瞄) |
| **R** | 换弹匣 |
| **左 Shift (L-Shift)** | 奔跑 |
| **Esc** | 暂停 / 退出游戏 |

## 🛠️ 运行与部署 (How to Run)

1. 确保您的电脑已安装 **Unreal Engine 5.4.4**。
2. 克隆或下载本项目压缩包并解压到本地。
3. 双击项目根目录下的 `.uproject` 文件打开工程。
4. 在 UE5 编辑器的内容浏览器中找到主关卡（Level），点击上方工具栏的 **Play (运行)** 按钮即可开始体验。

---

## 📁 目录结构简介 (Project Structure)

*(注：以下结构可根据你实际的文件夹名称自行调整)*
*   `Content/Blueprints/` - 存放玩家角色、丧尸 AI、武器及游戏模式控制器等核心蓝图。
*   `Content/Animations/` - 存放角色与丧尸的蒙太奇 (Montages)、动画蓝图 (AnimBP) 等资源。
*   `Content/UI/` - 包含准星、弹药量、倒计时显示等用户界面控件 (UMG)。
*   `Content/Maps/` - 存放游戏地图/关卡。
